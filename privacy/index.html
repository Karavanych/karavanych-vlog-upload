Политика конфиденциальности

Эта политика описывает обработку данных локальной программой Karavanych Vlog Upload, предназначенной для владельца канала «Караваныч, кипр и путешествия».

Какие данные используются

  • Идентификатор и название YouTube-канала — для проверки выбранного канала.
  • Выбранные владельцем видео и их параметры, например название, описание и видимость, — для загрузки в YouTube.
  • OAuth-токены и настройки клиента — для разрешённых владельцем обращений к YouTube Data API и обновления доступа.

Программа запрашивает разрешения youtube.upload и youtube.readonly. Пароль Google программа не запрашивает и не сохраняет: вход выполняется на странице Google.

Цель использования

Данные используются для проверки целевого канала, загрузки выбранных владельцем видео и поддержания авторизованного доступа. Они не продаются, не используются для рекламы и не применяются программой для обучения моделей искусственного интеллекта.

Где хранятся данные и кому передаются

Программа выполняется на компьютере владельца. Видео и их параметры передаются Google/YouTube через API для выполнения загрузки. Файлы авторизации сохраняются в указанной владельцем папке. Если эта папка синхронизируется, например через Dropbox, её содержимое также обрабатывается соответствующим провайдером хранения по настройкам и правилам аккаунта владельца. Отдельного сервера для хранения данных пользователей у программы нет.

Загруженные материалы и данные YouTube далее обрабатываются согласно политике конфиденциальности Google. Эта политика относится к локальной программе; сервер размещения этих информационных страниц может обрабатывать обычные технические журналы посещений сайта.

Срок хранения и удаление

Локальные видео, параметры и файлы авторизации сохраняются до их удаления владельцем. При использовании синхронизации или резервных копий сроки хранения дополнительных копий зависят от настроек и правил соответствующего провайдера. Удаление локального файла не удаляет ранее загруженное видео с YouTube.

Владелец может удалить файлы авторизации и отозвать доступ на странице подключений Google-аккаунта. Загруженными видео можно управлять в YouTube Studio.

Ограниченное использование данных Google

Использование программой данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use. Доступ ограничен описанными здесь функциями программы.
