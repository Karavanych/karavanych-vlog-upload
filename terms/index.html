Условия использования

Karavanych Vlog Upload — личная локальная программа Evgeny Karavashkin для загрузки видео на принадлежащий ему YouTube-канал. Публичная регистрация и предоставление доступа другим пользователям не предусмотрены.

Использование программы

Программа применяется только к каналу, которым владелец вправе управлять. Выбор файлов, параметры видео и запуск загрузки выполняются по указанию владельца. Владелец проверяет целевой канал, наличие прав на материалы и выбранную видимость перед загрузкой.

Правила YouTube и Google

Использование YouTube и его API регулируется условиями YouTube, условиями YouTube API Services и применимыми правилами Google. Программа является независимым приложением и не предоставляется Google или YouTube.

Доступность и ограничения API

Работа зависит от доступности Google API, действующей авторизации и квот проекта. Ошибка загрузки или сохранённый токен сами по себе не подтверждают публикацию видео. Результат следует проверять по ответу API и в YouTube Studio.

Данные и прекращение использования

Обработка данных описана в политике конфиденциальности. Владелец может прекратить использование программы, удалить локальные файлы авторизации и отозвать доступ в Google-аккаунте.
