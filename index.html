Загрузка видео на канал «Караваныч, кипр и путешествия»

Karavanych Vlog Upload предназначена для загрузки выбранных владельцем видео на его YouTube-канал с компьютера через YouTube Data API.

Как используется доступ

  1. Владелец проходит авторизацию Google и выбирает свой YouTube-канал.
  2. Программа проверяет идентификатор канала, чтобы использовать нужный канал.
  3. Владелец запускает загрузку выбранного видео и задаёт параметры публикации.

Запрашиваемые разрешения

youtube.upload — управление видео, необходимое для загрузки через API. youtube.readonly — просмотр данных YouTube-аккаунта для проверки выбранного канала.

Программа работает локально и предназначена для владельца канала. На этом сайте нельзя войти в программу, загрузить видео или передать OAuth-токен.

Данные и управление доступом

Видео передаются в YouTube по команде владельца. Файлы авторизации сохраняются в выбранной владельцем папке; при использовании синхронизируемой папки они могут синхронизироваться её провайдером. Подробности приведены в политике конфиденциальности.
